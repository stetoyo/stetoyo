# Time-Series Forecasting & Synthetic Data Generation

A machine learning pipeline for stock market price prediction using advanced generative models.

## Features
- LSTM seq2seq baseline model
- TimeGAN implementation for synthetic time-series generation
- Conditional Normalizing Flows for temporal dynamics modeling
- Comparative evaluation of generative architectures

## Files
- `Stock_Market_Generative_Prediction.ipynb` - Jupyter notebook with full implementation

## Tech Stack
- Python
- Machine Learning frameworks (TensorFlow/PyTorch)
- Generative Adversarial Networks (GANs)
- Normalizing Flows
